# Hi, I'm Aayush

I'm interested in economics, quantitative finance, and machine learning—mostly
the parts where a model has to survive contact with real code. I use these
projects to work through ideas, test the assumptions, and learn where the neat
version on paper starts to break down.

## Projects I've been working on

- [Liquidity Arbitrage Engine](https://github.com/meowcat234of-a11y/liquidity-arb-engine)
  is a small market simulator with an order book, market-making logic, and
  synthetic order flow.
- [Algorithmic Auction Dynamics](https://github.com/meowcat234of-a11y/algorithmic-auction-dynamics)
  connects auction simulations with adaptive bidding and a GPV estimator.
- [Macro Labor Automation Evaluation](https://github.com/meowcat234of-a11y/macro-labor-automation-eval)
  explores staggered treatment effects and synthetic-control counterfactuals
  using a reproducible FRED/BLS data pipeline.
- [Venture Graph Transformer](https://github.com/meowcat234of-a11y/venture-graph-transformer)
  is where I worked through transformer internals, graph construction, and a
  simple Streamlit explorer.

I try to keep each repository runnable from a fresh environment, add tests for
the parts that are easy to get subtly wrong, and write down the limitations
instead of pretending a research prototype is production software.
