## About me

I'm interested in economics, quantitative finance, and machine learning—mostly
the parts where a model has to survive contact with real code. I build small,
auditable projects to work through ideas, test the assumptions, and find where
the neat version on paper starts to break down.

## How I work

- Make the setup reproducible enough that someone else can run it.
- Test the parts that are easy to get subtly wrong.
- Keep assumptions close to the implementation.
- Call a research prototype a research prototype.

If one of these projects overlaps with something you're working on, feel free
to [get in touch](mailto:aayush.parashar@duke.edu).
